# 02. Границы MVP (этап 1, 7–27 октября 2026)

## Входит

1. Веб-кабинет с ролями «руководитель» и «кадровик»; вход по логину/паролю.
2. Ручной ввод данных работников и кандидатов, включая документы-удостоверения.
3. Валидаторы: контрольные суммы СНИЛС и ИНН, срок действия паспорта, совпадение ФИО.
4. Пять процессов как машины состояний:
   - приём на работу (с испытанием или без)
   - испытательный срок (напоминание, решение, увольнение по ст. 71)
   - отпуска (начисление, график, уведомления, Т-6, перенос, отзыв, замена, без сохранения)
   - увольнение по собственному желанию (с расчётом)
   - увольнение по соглашению сторон
5. Все 22 шаблона документов → DOCX и PDF, с версионированием шаблона.
6. Реестр из 78 правил, загруженный из `legal-package/01-RULES-REGISTRY.md` в БД,
   с версиями и полем `verified_by / verified_at` (пустым).
7. Линтер реестра: каждый параметр правила имеет точку исполнения в коде.
8. Очередь решений руководителя (A2): подтвердить / отклонить / отложить, с контекстом проверок.
9. Календарь 16 обязательств перед госорганами: расчёт сроков, формирование пакетов,
   валидация формата, отправка в заглушку оператора с имитацией квитанции.
10. Производственный календарь 2025–2027 как данные с источником.
11. Журнал аудита append-only с хеш-цепочкой.
12. Шифрование ПДн-колонок.
13. Генерация пакета правовой верификации (документы 01, 04, 05) из реестра —
    чтобы юрист проверял ровно то, что реализовано.
14. Инструкция кадровика (короткая, markdown).

## Не входит — не делать, даже если просто

- ИИ-агент, чат, LLM в любом виде
- Страница кандидата, кабинет работника, Telegram-бот
- Реальная отправка в госорганы, реальная ЭП (только имитация: кто и когда «подписал»)
- OCR, 1С, отзыв доступов во внешних системах (только задача человеку)
- Уведомления работникам по email/SMS (только внутри кабинета)
- Больничные как сущность (этап 2, по вердикту юриста)
- Отзыв заявления об увольнении, категории без испытания сверх возраста,
  согласие работника на отзыв из отпуска — **реализуются на этапе 2 по вердикту юриста**;
  в MVP оставить точки расширения (состояние/поле), но не логику
- Совместительство, неполное время, дистанционная работа, инвалиды, доп. отпуска
- Расчёт зарплаты (кроме расчёта при увольнении, как в реестре)
- Увольнение по инициативе работодателя, сокращение, дисциплинарные взыскания — A3

## Критерии приёмки этапа 1 (акт № 1)

Демонстрация на тестовых данных заказчика:

1. Полный цикл одного сотрудника: приём с испытанием → решение по испытанию →
   отпуск по графику → увольнение по собственному желанию с расчётом.
   Все документы открываются в PDF с реквизитами заказчика.
2. Годовой график отпусков на 2027 для отдела из 10 человек: все 28 дней,
   часть ≥ 14, не более половины отдела одновременно, утверждение в очереди руководителя.
3. Календарь обязательств после приёма и увольнения показывает сроки, виды дней
   и сформированные пакеты; заглушка возвращает квитанции.
4. Журнал аудита показывает цепочку действий с версиями правил; попытка UPDATE отклоняется.
5. `lint_registry.py` проходит без ошибок; пакет верификации генерируется командой.
6. Тесты расчёта дат и расчётов при увольнении проходят на контрольных примерах.
