# 03. Бэклог MVP — 3 недели, по блокам и задачам

Оценки в часах ориентировочные, на одного разработчика; план рассчитан на двоих
(≈ 240 ч суммарно). Отмечай `[x]` и фиксируй фактические часы для дневного акта.

---

## Неделя 1 · 7–13 октября · Фундамент и данные

### Блок 1.1 Инфраструктура (≈ 10 ч)
- [x] Монорепо: `backend/`, `frontend/`, `templates/`, `docs/`; `.gitignore`, `.env.example`
- [x] `docker-compose.yml`: postgres, redis, minio, api, worker, beat, frontend, soffice
- [x] FastAPI скелет, settings через pydantic-settings, healthcheck (`/health`, `/health/live`)
- [x] Alembic, первая миграция `0001`, роль БД `audit_writer` без UPDATE/DELETE
      (права + триггер, тесты `tests/test_audit_log_schema.py`)
- [x] CI: lint (ruff), tests (pytest c Postgres/Redis), сборка образов (`.github/workflows/ci.yml`)
- [ ] Развёрнуть на тестовом стенде, бэкап Postgres по cron — скрипты готовы
      (`deploy/stand-up.sh`, `deploy/backup-postgres.sh`, `deploy/crontab.example`,
      инструкция `docs/05-STAND.md`); нужен адрес сервера от заказчика

### Блок 1.2 Авторизация и роли (≈ 8 ч)
- [ ] Модели `organizations`, `users` (director | hr), пароли argon2, JWT
- [ ] Мультитенантность: `organization_id` на всех таблицах, фильтр в зависимостях
- [ ] Тестовые учётные записи для заказчика

### Блок 1.3 Реестр правил (≈ 16 ч)
- [ ] Модели `rules`, `rule_versions` (name, version, trigger, action, params jsonb,
      autonomy A0–A3, norm, flags, verified_by, verified_at)
- [ ] Парсер `legal-package/01-RULES-REGISTRY.md` → seed YAML `registry/seed/rules.yaml`
      (78 правил; все параметры из колонок «срок», «исключения», «параметры»)
- [ ] Загрузчик seed → БД, идемпотентный
- [ ] Декоратор/реестр `@implements_rule("name", params=[...])` в коде
- [ ] `scripts/lint_registry.py`: правило без реализации или параметр без точки
      исполнения → ошибка; A3 в коде → ошибка
- [ ] Тест: все 78 правил загружены, суммы по разделам 23/14/27/14

### Блок 1.4 Производственный календарь и даты (≈ 8 ч)
- [ ] Таблица `production_calendar`, seed 2025–2027 с источником и датой публикации;
      2027 помечен «предварительный»
- [ ] `app/calendar`: add_calendar_days, add_working_days, add_months, next_working_day
- [ ] Тесты: 31.03 + 1 мес, 29.02, перенос с выходного, срок в рабочих днях через праздники

### Блок 1.5 Работники и документы (≈ 14 ч)
- [ ] Модели `employees`, `candidates`, `employee_documents`; encrypted-колонки для
      паспорта, СНИЛС, ИНН (ключ на организацию, через `pgcrypto` или app-level)
- [ ] Валидаторы: контрольные суммы СНИЛС, ИНН 12 знаков, срок паспорта по возрасту,
      нормализация и сравнение ФИО
- [ ] Штатное расписание: должности, ставки, занятость
- [ ] API: CRUD работника/кандидата, загрузка документов, результат проверок
- [ ] Фронт: список работников, карточка, форма «новый кандидат» с результатами проверок

**Результат недели:** проверенная карточка работника в кабинете.

## Неделя 2 · 14–20 октября · Приём и испытание

### Блок 2.1 Движок процессов (≈ 10 ч)
- [ ] Базовый класс процесса: состояния, переходы, `rule_version_ids` на старте,
      `process_events`
- [ ] Политика автономии: `prepare()` / `execute()`; A2 → запись в `decisions`;
      проверка уровня до вызова; попытка вызвать A3 — не компилируется/не существует
- [ ] Аудит: `audit_log` с prev_hash/hash, писатель через роль `audit_writer`,
      тест «UPDATE отклоняется»

### Блок 2.2 Очередь решений руководителя (≈ 8 ч)
- [ ] Модель `decisions`, статусы pending / approved / rejected / postponed
- [ ] API + фронт: список, карточка с контекстом проверок и предупреждений, три кнопки
- [ ] Имитация ЭП: фиксируется кто/когда, флаг `signature_simulated=true`

### Блок 2.3 Документы (≈ 12 ч)
- [ ] Модели `templates`, `template_versions`, `generated_documents`
- [ ] Рендер: docxtpl → DOCX → PDF через soffice-контейнер; хранение в MinIO
- [ ] Шаблоны приёма: трудовой договор, Т-1, Т-2, лист ознакомления, согласие ПДн,
      согласие КЭДО, заявление о способе ведения ТК, договор о МО
      (поля — из `legal-package/03-DOCUMENTS.md`; тексты — типовые формы, ⚠ не проверены)
- [ ] Просмотр и скачивание PDF/DOCX из карточки процесса

### Блок 2.4 Процесс «Приём» (≈ 16 ч)
- [ ] Состояния: draft → documents_check → prehire_checks → consents → package_draft →
      awaiting_director → signed → completed | blocked
- [ ] Проверки (все через правила реестра): штатное расписание, возраст, иностранец,
      воинский учёт, бывший госслужащий, медосмотр, пределы испытания
- [ ] После подписания: приказ Т-1 (A2), внутренний воинский учёт (A0), старт стажа
      отпуска, таймер испытания, порождение обязательств
- [ ] Фронт: мастер приёма по шагам, экран блокировок

### Блок 2.5 Процесс «Испытательный срок» (≈ 8 ч)
- [ ] Расчёт даты окончания по правилу реестра (как в реестре; см. 04-DOMAIN-NOTES B1)
- [ ] Celery beat: напоминание руководителю за 5 дней
- [ ] Решение: passed → completed; failed → уведомление за 3 дня (документ) → процесс
      увольнения по ст. 71
- [ ] Автоматическое исключение условия об испытании для несовершеннолетних (как в реестре)

**Результат недели:** приём первого сотрудника с договором и Т-1, испытание на таймере.

## Неделя 3 · 21–27 октября · Увольнения, отпуска, обязательства, приёмка

### Блок 3.1 Отпуска (≈ 14 ч)
- [ ] `vacation_balances`: ежемесячное начисление 2,33 (Celery beat), округление по реестру
- [ ] Генератор проекта графика: 28 дней, часть ≥ 14, ≤ 50 % отдела, приоритет остатков
- [ ] Утверждение графика — A2, срок до 17 декабря (из реестра)
- [ ] Таймеры по каждому отпуску: −30 напоминание, −14 уведомление (документ),
      −7 Т-6 (A2), −5 задача бухгалтерии
- [ ] Операции: перенос, отзыв (решение руководителя; согласие работника — точка
      расширения), замена части деньгами, отпуск без сохранения
- [ ] Квартальная проверка остатков, подсветка > 2 лет без отпуска
- [ ] Шаблоны: график Т-7, уведомление об отпуске, Т-6, заявления

### Блок 3.2 Увольнения (≈ 16 ч)
- [ ] «По собственному желанию»: заявление → дата по правилу (+14 / +3 / без отработки)

      за отпуск / удержание за аванс, выходное пособие, НДФЛ (**как в реестре**,
      см. 04-DOMAIN-NOTES B2–B6)
- [ ] «По соглашению сторон»: соглашение о расторжении (A2, две подписи) → далее общий трек
- [ ] Шаблоны: Т-8, Т-61, СТД-Р, обходной лист, соглашение о расторжении,
      уведомление ст. 71
- [ ] Пост-действия: задача «отозвать доступы», архив личного дела (срок — по реестру),
      порождение обязательств
- [ ] Точки расширения без логики: `withdrawn_at` для отзыва заявления, флаг

### Блок 3.3 Обязательства и заглушка ЭДО (≈ 12 ч)
