# 00. Описание проекта «AI-Кадровик»

## Что это

Программа-кадровик для небольшой компании (РФ). Руководитель говорит, что нужно сделать
с сотрудником, — система собирает документы, проверяет, что закон не нарушается, считает
сроки и суммы, готовит бумаги на подпись и сдаёт отчёты в госорганы. Там, где решение
юридически значимое, она останавливается и ждёт человека. Там, где функция опасна,
её просто нет.

## Пользователи

| Роль | Что делает |
|---|---|
| **Руководитель** | Подписывает ЭП, подтверждает действия A2: приём, увольнение, график отпусков, ЛНА. Интерфейс — очередь решений |
| **Кадровик** | Ведёт процессы, вводит данные (в MVP — вручную), подтверждает «прочие» A2 |
| **Работник** | Видит свои документы, подписывает, спрашивает ассистента (не в MVP) |
| **Кандидат** | Загружает документы по временной ссылке, без аккаунта (не в MVP) |
| **Правовой редактор (юрист)** | Ведёт реестр правил, проставляет «подтвердил» (этап 2) |

## Четыре уровня автономии

| Уровень | Смысл | В коде |
|---|---|---|
| **A0** | Делает сама, человек узнаёт из журнала | Выполняется сразу, пишет аудит |
| **A1** | Уведомляет, ждёт 2–48 ч, делает; можно отменить | Таймер + уведомление + отмена. Окно не может сорвать срок. Первые 30 дней и первая отправка каждого вида — как A2 |
| **A2** | Готовит всё, ждёт подтверждения человека | Очередь решений, кнопки подтвердить / отклонить / отложить |
| **A3** | Не делает никогда | Функции нет: ни эндпоинта, ни флага |

Ужесточить настройкой можно, смягчить ниже минимума — нет.

## Сценарии (полный список, в MVP — отмеченные ✓)

1. ✓ **Приём на работу** — ввод данных → проверки документов → проверки ограничений
   (возраст, иностранец, воинский учёт, бывший госслужащий, медосмотр) → согласия →
   пакет: договор, Т-1, Т-2, лист ознакомления, [договор о МО] → подпись руководителя →
   воинский учёт внутри, старт стажа отпуска, таймер испытания, обязательства.
2. ✓ **Испытательный срок** — проверка допустимости (возраст; остальные категории — см.
   `04-DOMAIN-NOTES`) → дата окончания → напоминание за 5 дней → решение → при провале
   увольнение по ст. 71 с уведомлением за 3 дня.
3. ✓ **Отпуска** — начисление 2,33/мес → проект графика (28 дней, часть ≥ 14, ≤ 50 %
   отдела) → утверждение до 17 декабря → за 30 дн напоминание, за 14 дн уведомление,
   за 7 дн Т-6, за 5 дн задача бухгалтерии → квартальная проверка остатков. Перенос,
   отзыв, замена деньгами, без сохранения.
4. ✓ **Увольнение по собственному желанию** — заявление → дата +14 дн (+3 на испытании,
   без отработки по уважительной причине) → проверки (МОЛ → инвентаризация, спор → стоп)
   → расчёт (зарплата, компенсация/удержание отпуска, пособие, НДФЛ) → Т-8, Т-61, СТД-Р,
   обходной → подпись → выплата в день увольнения → отзыв доступов, архив, отчётность.
5. ✓ **Увольнение по соглашению сторон** — то же, дата по соглашению, плюс соглашение
   о расторжении до приказа.
6. Увольнение по истечении срока договора — уведомление за 3 дня.
7. ✓ Изменения в ходе работы — перевод, изменение оклада/режима, штатное расписание, ГПХ.
8. ✓ **Отчётность в госорганы (16 обязательств)** — расчёт сроков и формирование
   пакетов; в MVP отправка в заглушку.
9. ЛНА и КЭДО — перевод на КЭДО, утверждение ЛНА, рассылка на ознакомление.
10. Ассистент — ответы работникам, правовые справки со ссылкой на норму.
11. **Никогда:** подпись за директора, переводы денег, дисциплинарные взыскания,
    увольнение по инициативе работодателя, сокращение, отказ кандидату, передача ПДн
    третьим лицам, изменение журнала и своих правил, правовые ответы без нормы.
