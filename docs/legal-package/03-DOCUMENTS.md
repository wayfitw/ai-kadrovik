# 03. Документы, которые формирует система

> Документ сформирован автоматически из библиотеки шаблонов 28.08.2026. Перечень полей извлечён из самих шаблонов.

**Всего форм: 22.** Ни один шаблон не подтверждён юристом.

## Принцип формирования документов

Программа **не сочиняет текст документов**. Каждый документ собирается из заранее заготовленного шаблона: в фиксированный текст подставляются данные работника и организации. Языковая модель в этом не участвует.

Практическое следствие для проверки: достаточно проверить текст шаблона один раз — все документы, созданные по нему, будут дословно совпадать, кроме подставленных значений. Полные тексты шаблонов приведены в приложении к настоящему документу (файл `03a-DOCUMENT-TEMPLATES-FULL.md`).

Каждый созданный документ хранит номер версии шаблона, по которому он был создан. Изменение шаблона не затрагивает ранее выпущенные документы.

## Что нужно проверить

1. **Полноту обязательных условий.** Для трудового договора — соответствие ст. 57 ТК РФ: все ли обязательные условия присутствуют.
2. **Корректность формулировок** оснований увольнения, срочности договора, условий об испытании.
3. **Достаточность полей.** Отмечено ли поле как обязательное там, где документ без него недействителен.
4. **Соответствие унифицированным формам** (Т-1, Т-2, Т-6, Т-7, Т-8, Т-61), если организация их применяет.
