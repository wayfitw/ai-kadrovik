# 01. Реестр правовых правил, реализованных в системе

> Документ сформирован автоматически из реестра правил системы 28.08.2026. Он описывает **то, что фактически делает программа**.

**Всего правил: 78.** Ни одно из них на дату формирования документа не подтверждено юристом: поле «подтвердил» в реестре пусто у всех записей.

## Как читать таблицу

| Колонка | Что означает |
|---|---|
| **ID правила** |Уникальный код записи в реестре. По нему правило можно найти и исправить. Формат: `имя vN`, где N — номер версии. |
| **Когда срабатывает** | Событие в кадровом процессе, после которого правило применяется. |
| **Что делает система** | Действие, которое программа выполняет или готовит. |
| **Срок** | Как программа вычисляет крайнюю дату. Считается по производственному календарю РФ (см. документ 06, раздел о календаре). |
| **Исключения и параметры** | Числовые пределы, категории работников, обстоятельства, заложенные в правило. |
| **Документы** | Формы и документы, которые правило порождает. |
| **Правовое основание** | Норма, на которую ссылается программа. **Именно это и требует проверки.** |
| **Автоматизация** | A0 — делается само; A1 — само, но человек уведомлён заранее и может отменить; A2 — только после подтверждения человека; A3 — программе запрещено. |
| **Подтверждение человека** | Требуется ли явное решение уполномоченного лица. |

## Что именно нужно проверить в каждой строке

1. **Верна ли норма** в колонке «Правовое основание» — существует ли она, действует ли в текущей редакции, относится ли к описанной ситуации.
2. **Верен ли срок** — количество дней, вид дней (рабочие или календарные), момент, с которого срок отсчитывается.
3. **Полны ли исключения** — не упущены ли категории работников или обстоятельства, при которых правило не применяется или применяется иначе.
4. **Достаточен ли уровень контроля человека** — не является ли действие слишком рискованным для выбранного уровня автоматизации.
